# Changelog

## 0.1.0-draft — 2026-08-26

Initial public draft:

- ZIP-compatible `.cdp` package with `manifest.json` and `document.json`.
- Ordered UUID-addressed document blocks.
- Sparse clinical semantics: omission is not an explicit negative finding.
- Common coding, identifier, quantity, finding, and attachment-reference primitives.
- Core guidance for narrative, examination, medication, investigation, diagnosis, and advice blocks.
- Optional presentation hints separated from clinical meaning.
- Attachment integrity via SHA-256.
- Extension namespace mechanism.
- JSON Schemas and Python reference validator.
- Fictional examples and reproducible example package builder.
